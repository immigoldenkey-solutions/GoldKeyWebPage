## 🎯 Cómo Usar Figma con Tu Sitio

### Opción 1: Exportar Assets

#### Exportar Imágenes:

1. Selecciona elemento en Figma
2. Panel derecho → "Export"
3. Formato: PNG (transparente) o JPG
4. Resolución: 2x o 3x (mejor calidad)
5. Click "Export"

#### Usar en tu Web:

```html
<!-- Reemplaza en index.html -->
<img src="tu-nueva-imagen.png" alt="Descripción">
```

### Opción 2: Plugin Figma to HTML

#### Plugins Recomendados:

1. **Figma to Code (HTML/CSS/React)**
   - Plugins → Browse → "Figma to HTML"
   - Selecciona elementos
   - Genera código automáticamente

2. **Anima - Export Figma to HTML**
   - Exporta diseños completos
   - Genera HTML responsive

#### Pasos:

1. Diseña en Figma
2. Plugins → "Figma to HTML"
3. Copia código generado
4. Pega en tu `index.html`

## 🛠️ Flujo de Trabajo Recomendado

```

   ↓

   ↓
```

## 🆘 Troubleshooting

### Problema: "Fuente no disponible"
**Solución**: Descarga e instala la fuente desde Google Fonts

### Problema: "Exportación muy pesada"
**Solución**: 
1. Reduce calidad de exportación
2. Usa TinyPNG para comprimir
3. Convierte a WebP

### Problema: "Colores diferentes en web"
**Solución**: Exporta en RGB, no CMYK
